Marea Studio — Widget de prueba

Dogfood E2E del agente vía Chatwoot real.

Cómo usarlo
  1. Abre la burbuja de chat (abajo a la derecha).
  2. Escribe como si fueras un cliente. Por ejemplo:

Hola, ¿en qué estado está mi pedido 1181?

El mensaje entra por la cuenta Chatwoot Purigu → webhook /webhooks/chatwoot → tenant marea-studio → el agente responde de vuelta en esta misma conversación.
